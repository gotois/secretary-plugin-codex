# Day planning

Для прямого запроса доступности вызови `check-availability` для указанного
интервала. «Сегодня» означает полный текущий день в локальном часовом поясе
пользователя. Метод проверяет календарь текущего пользователя: не спрашивай,
какой ресурс проверять. Перечисли все busy-интервалы; пустой ответ означает
доступность на весь интервал.

Для прямого запроса доступности не вызывай `list-calendar-tasks`:
`list-calendar-tasks` читает задачи и события, а `check-availability` —
free/busy rules. Если пользователь назвал `check-availability`, используй
именно этот tool.

1. Прочитай задачи через `list-calendar-tasks` и доступность через
   `check-availability`; спроси только критичные ограничения, например время
   подъёма или жёсткий дедлайн.
2. Считай данные fitness tracker, сна и энергии недоступными, пока их не дал
   пользователь или tool. Не выдумывай такие данные.
3. Предложи расписание до любых изменений: сохрани фиксированные события,
   покажи конфликты, буферы, перерывы и допущения. Pomodoro и 8+8+8 — гибкие
   эвристики, а не обязательные правила.
4. Не изменяй существующие задачи и не создавай новые без явного подтверждения.
5. Для сохранения новой задачи переключись на `$task-intake`, проверь
   доступность, вызови `prepare-create-form` и дождись подтверждения UI.
