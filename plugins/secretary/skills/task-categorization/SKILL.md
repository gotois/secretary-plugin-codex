# Task categorization

Выбирай ровно одну из четырёх database categories Secretary:

- `1` — Работа: оплачиваемая работа, профессиональные проекты, отчёты
  и встречи команды.
- `2` — Дом: бытовые дела, ремонт, коммунальные услуги и домашняя
  логистика.
- `3` — Отдых: развлечения, путешествия и восстановление.
- `4` — Личное: здоровье, обучение, упражнения, финансы и другие
  личные дела.

## Workflow

1. Используй цель, `name` и `description` задачи; не выбирай категорию по
   месту, времени или одному неясному слову.
2. При сомнении между двумя категориями выбирай по основному результату.
   Задай один вопрос, только если выбор существенно меняет смысл задачи.
3. Верни `id_category`, название и одну короткую причину. Внутри
   `$task-intake` передай в draft только `id_category`.

## Guardrails

- Не выдумывай пятую категорию и не переименовывай существующие.
- Не смешивай эти категории с двенадцатью аналитическими сферами
  `$life-balance`.
- Не вызывай MCP tool ради категоризации: список из четырёх категорий
  вшит в этот skill.
